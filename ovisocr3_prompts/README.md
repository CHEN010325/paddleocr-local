# Official OvisOCR3 document prompts

Source: https://huggingface.co/ATH-MaaS/OvisOCR3/tree/4833d5d2afa6e769ee933f024504d67ace80a24c/prompts

The three text files are copied unchanged from the pinned Apache-2.0 model repository.
The adapter selects structured or Markdown document parsing. Other task families from
the model card are not exposed as separate workbench features by this integration.
